# 🏥 Healthcare Patient Experience Analytics using Power BI

> An end-to-end Business Intelligence project that transforms Healthcare Patient Experience (HCAHPS) survey data into interactive dashboards using Microsoft Power BI, enabling healthcare leaders to monitor performance, benchmark results, and make data-driven decisions.

---

## 📌 Project Overview

Healthcare organizations collect patient experience data through HCAHPS surveys to evaluate the quality of care delivered to patients. However, analyzing this data across multiple states, measures, and reporting periods can be challenging.

This project leverages **Microsoft Power BI** to transform raw healthcare survey data into meaningful insights through interactive dashboards, KPI reporting, and executive-level analytics. It demonstrates the complete Business Intelligence lifecycle—from data preparation and modeling to visualization and business recommendations.

---

## 🎯 Business Problem

Healthcare survey data is distributed across different states, quality measures, and reporting periods, making it difficult for stakeholders to:

- Monitor patient satisfaction
- Compare state performance
- Benchmark against national averages
- Identify improvement opportunities
- Track healthcare performance over time

This project centralizes the data into an interactive Power BI solution to support informed, data-driven decision-making.

---

## 🎯 Project Objectives

- Build an interactive Healthcare Analytics Dashboard using Power BI
- Transform and clean raw healthcare data using Power Query
- Design an optimized Star Schema data model
- Develop dynamic KPIs using DAX
- Analyze patient satisfaction across states and regions
- Compare state performance with national benchmarks
- Generate actionable business insights and executive recommendations
